# Application icon

The owner-approved OpenApe Pods icon uses a forest-green tile and an ivory ape face.
`openape-pods.png` is the 1024 px RGBA source; `openape-pods.icns` contains all
standard macOS sizes from 16 to 1024 px. Both fixture and distribution packages
use the same icon through `scripts/package.mjs`.

Created with OpenAI image generation for OpenApe Pods on 2026-09-14, approved by
Patrick Hofmann. Packaging includes the icon before signing; do not modify a
signed application bundle to replace its icon.
