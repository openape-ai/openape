Creating a company

A new account starts with no companies. This is the first thing to do.

1 Open Companies

Every company you run is listed here.

2 Name the company and write its vision

The Operator reads the vision on every interaction, so write it for a colleague.

3 Select Create

The company appears in the list, ready to be opened.
