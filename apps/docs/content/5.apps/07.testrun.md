## Publish test evidence

Install `@openape/ape-testruns` to get `ape-reports` and `ape-report-render`.
Create the run manifest from actual checks and personally inspect its screenshots.

```sh
ape-report-render test-run run/testrun.json verification.html --commit COMMIT --command 'pnpm test'
ape-reports preview verification.html --check
ape-reports publish verification.html --category 'Test Runs' --key RUN_KEY
```

The template puts failures first and keeps skipped checks visible. It embeds
screenshots into one portable HTML file, works on narrow screens, and supports
light and dark themes. Missing or oversized evidence fails before publication.

Reports returns a `/d/ID` link. Documents are private and permanent by default;
a link alone grants no access. Choose a team, named readers or public access only
when intended. Updates require the original version and a stable publication key.
Old shared proof links remain available under their existing access rules.
