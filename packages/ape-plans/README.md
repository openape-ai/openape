# @openape/ape-plans (deprecated compatibility CLI)

For new work, install `@openape/ape-testruns`: `ape-report-render` creates Plans
and Test Runs locally; `ape-reports` publishes the resulting HTML and manages teams.
Read the [Reports guide](../ape-testruns/README.md) and [input contract](../ape-testruns/RENDERING.md).

This CLI remains available during the migration and observation period. Existing
Plans links and immutable versions retain their access rules. Shared authentication
still uses `apes login`; per-CLI login is obsolete. Legacy source replacement requires
the version originally read. Use the installed command help for compatibility flags.

Removal is conditional on the producer inventory and seven verified quiet days;
package deprecation alone does not remove service endpoints or old documents.
