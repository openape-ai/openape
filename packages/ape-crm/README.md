# @openape/ape-crm

CLI for [crm.openape.ai](https://crm.openape.ai) — deal pipeline, contacts and
notes for humans and AI agents.

```bash
npm i -g @openape/ape-crm
apes login you@example.com          # once per device, shared by all OpenApe CLIs
ape-crm workspaces new --name "Delta Mind"
ape-crm deals new --title "Website-Relaunch" --value 18000
ape-crm deals
```

Full guide: `ape-crm docs cli` · agent reference: `ape-crm docs agent`.
